# ISHA – GGUF Runtime Installation Problem Fix

Mere current ISHA project me Ollama ko replace karke direct GGUF + `llama-cpp-python` use kiya gaya hai.

Lekin startup par ye error aa raha hai:

```text
[gguf] llama-cpp-python missing — pip install llama-cpp-python
```

Maine terminal me:

```bash
pip install llama-cpp-python
```

run karne ki koshish ki, lekin installation fail/error de rahi hai.

## IMPORTANT

Mujhe sirf error message hide ya bypass nahi karna hai.

Mujhe actual root cause fix karna hai.

Current ISHA code me `.isha_runtime` naam ka dedicated Python virtual environment/runtime use hota hai. Isliye ensure karo ki `llama-cpp-python` **usi Python environment me install aur import ho jahan ISHA actually run ho raha hai**.

# 2. Fix the Python Environment Issue

Current project apna runtime:

```text
.isha_runtime/
```

use karta hai.

Ensure karo ki:

```text
llama-cpp-python
```

system/global Python me nahi, balki **ISHA ke actual runtime Python** me install/check ho.

Runtime Python ko dynamically detect karo.

Conceptually:

```text
ISHA
 ↓
.isha_runtime
 ↓
.isha_runtime/bin/python
        OR
.isha_runtime/Scripts/python.exe
 ↓
llama-cpp-python
 ↓
GGUF
```

Platform ke according correct Python executable use karo.

Linux:

```text
.isha_runtime/bin/python
```

Windows:

```text
.isha_runtime/Scripts/python.exe
```

---

# 3. Do NOT Simply Use `pip`

Dependency installation ke liye blindly:

```bash
pip install llama-cpp-python
```

use mat karo.

Instead, runtime ke exact Python interpreter ke through pip run karo:

```bash
<runtime_python> -m pip install llama-cpp-python
```

Isse package exactly us environment me install hoga jisme ISHA run hota hai.

---
